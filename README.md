# BTCS — بازارهای زنده ارز دیجیتال، سیگنال‌ها و پیش‌بینی‌های هوش مصنوعی

[![CI](https://github.com/webiran0x/BTCS/actions/workflows/ci.yml/badge.svg)](https://github.com/webiran0x/BTCS/actions/workflows/ci.yml)[cite: 26]

**دموی زنده:** https://webiran0x.github.io/BTCS/

یک وب‌سایت قابل نصب برای بازارهای زنده ارز دیجیتال: قیمت‌ها، نمودارهای سبک بایننس، سیگنال‌های اندیکاتوری، مقایسه تاریخچه‌ چندساله، شبیه‌ساز معاملات (paper-trading) و پیش‌بینی بازه قیمتی با هوش مصنوعی که به‌طور مستقیم روی دستگاه شما اجرا می‌شود — **بدون نیاز به کلیدهای API پولی**. دقت هر مدل اندازه‌گیری شده و در کنار آن منتشر می‌شود، از جمله جاهایی که عملکردی بهتر از یک مبنای ساده ندارد. این برنامه روی گوشی‌ها و رایانه‌ها به یک اندازه کار می‌کند.

> سیگنال‌ها، پیش‌بینی‌ها، پاسخ‌های هوش مصنوعی و شبیه‌ساز معاملات ابزارهای آموزشی هستند و مشاوره مالی محسوب نمی‌شوند. نتایج شبیه‌سازی‌شده و گذشته تضمین‌کننده بازدهی‌های آینده نیستند. این سایت هرگز معاملاتی را ثبت نمی‌کند و هرگز درخواست کلیدهای API صرافی، کلیدهای خصوصی یا عبارت‌های بازیابی (Seed Phrase) را نمی‌کند.

برنامه از طراحی مشابهی بهره می‌برد: ابسیدین، عاجی و طلایی شامپاینی، فونت Cormorant Garamond روی Manrope، پنل‌های شیشه‌ای روی یک دنیای سه‌بعدی زنده. این دنیا به عنوان یک تالار معاملاتی است: یک نمودار کندل‌استیک سه‌بعدی از کندل‌های ساعتی واقعی در یک قوس پشت همه‌چیز قرار دارد.

## ویژگی‌ها[cite: 26]

| بخش | عملکرد آن[cite: 26] |
|---|---|
| **بازارها (Markets)** | ۲۵۰ کوین برتر (با پشتیبانی CoinGecko و جایگزین CoinPaprika)، قیمت‌های زنده از طریق وب‌سوکت بایننس، تغییرات ۱ ساعته/۲۴ ساعته/۷ روزه، اسپارک‌لاین‌ها، ارزش کل بازار، دامیننس BTC/ETH، شاخص ترس و طمع، ترندها، بیشترین رشد/افت، نقشه حرارتی و واچ‌لیست[cite: 26]. |
| **صفحه کوین (Coin page)** | نمودار کندل‌استیک زنده (از ۱ ثانیه‌ای تا هفتگی) با قابلیت زوم/پن/پینچ، میانگین متحرک نمایی ۲۰/۵۰/۲۰۰، باندهای بولینگر، حجم، RSI، MACD، حمایت/مقاومت، نشانگرهای بک‌تست و مخروط پیش‌بینی هوش مصنوعی[cite: 26]. کوین‌هایی که بایننس لیست نکرده است به صورت زنده از Gate.io، HTX یا OKX روی وب‌سوکت استریم می‌شوند[cite: 26]. |
| **سیگنال معامله (Trade signal)** | امتیاز خرید/فروش (بین ۱۰۰- تا ۱۰۰+) از ۹ گروه اندیکاتور، تلاقی چند تایم‌فریم، ناحیه ورود، حد ضرر، سه حد سود، قوانین خروج و دلایل[cite: 26]. |
| **پیش‌بینی هوش مصنوعی (AI forecast)** | با بازه‌های قیمتی ۸۰٪ و ۹۰٪ و میزان پایداری آن‌ها در تست‌ها شروع می‌شود، سپس احتمال صعود را نشان می‌دهد[cite: 26]. مجموعه‌ای از ۷ مدل که در مرورگر روی تاریخچه خود کوین آموزش دیده‌اند[cite: 26]. |
| **تاریخچه و چرخه‌ها (History & cycles)** | مطالعه بلندمدت: هر بازه گذشته ۴۵ روزه که فرم آن با امروز مطابقت داشته را پیدا می‌کند، عملکرد قیمت را ۷/۳۰/۹۰ روز بعد نشان می‌دهد[cite: 26]. |
| **بک‌تست (Backtest)** | منحنی سرمایه در مقایسه با خرید و نگهداری، نرخ برد، افت سرمایه و لیست معاملات[cite: 26]. |
| **آتی (Futures)** | نرخ تامین مالی، فاندینگ سالانه، بیس، سود باز و تغییرات ۱۲ ساعته آن، نسبت‌های حساب‌های لانگ/شورت و فید لیکوییدیشن زنده[cite: 26]. |
| **ابزارها (Tools)** | مبدل کوین به ارز (PKR و ۱۵ ارز دیگر)، بک‌تست DCA روی قیمت‌های بسته شدن روزانه واقعی و ماشین‌حساب اندازه موقعیت[cite: 26]. |
| **معاملات (Trading)** | سه حساب در کنار یکدیگر: معاملات آزمایشی که خودتان ثبت می‌کنید، معاملات واقعی که ثبت می‌کنید، و هوش مصنوعی که استراتژی تست‌شده‌ای را روی پول شبیه‌سازی‌شده اجرا می‌کند[cite: 26]. |

## هوش مصنوعی داخلی (بدون نیاز به کلید API)[cite: 26]

1. **موتور پیش‌بینی (`js/lib/predict.js`)** در یک Web Worker اجرا می‌شود و از هفت مدل استفاده می‌کند:
   - تطبیق الگوی نمودار در برابر تاریخچه کوین[cite: 26]
   - حرکات مشابه گذشته[cite: 26]
   - درخت‌های تصمیم‌گیری تقویت‌شده با گرادیان[cite: 26]
   - شبکه عصبی (بگ دو مدلی)[cite: 26]
   - رگرسیون لجستیک[cite: 26]
   - نزدیک‌ترین همسایگان[cite: 26]
   - مدل روند هولت[cite: 26]
2. **موتور تاریخچه (`js/lib/history.js`)** روی کندل‌های روزانه کار می‌کند تا بتواند بازارهای صعودی و نزولی قبلی را پوشش دهد[cite: 26].
3. **مدل زبانی (`js/ai/engine.js`)** مدل Qwen 3.5 را مستقیماً روی GPU کاربر از طریق WebGPU اجرا می‌کند[cite: 26].
4. **تحلیل‌گر مبتنی بر قوانین (`js/lib/analyst.js`)** روی هر دستگاهی از جمله گوشی‌های بدون WebGPU به‌سرعت پاسخ می‌دهد[cite: 26].

## اجرای محلی (Run locally)[cite: 26]

بدون نیاز به مرحله ساخت (Build step) و بدون وابستگی‌ها: فایل‌های خالص HTML، CSS و ES modules[cite: 26].

```bash
node tools/serve.mjs 8080      # سپس http://localhost:8080 را باز کنید
node --test tests/*.test.mjs   # تست‌های واحد
node tools/smoke.mjs           # لود کردن هر صفحه در مرورگر واقعی (نیاز به پلی‌رایت)
